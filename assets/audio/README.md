# Selected soundtrack assets

Place the three original MP3 files in this directory using these exact names:

- `menu-cinematic-nastelbom.mp3` — “Cinematic” by NastelBom (menu), https://pixabay.com/music/ambient-cinematic-485889/
- `challenge-epic-cinematic-journey-apex.mp3` — “Epic Cinematic Journey - APEX” by Artur_Aravidi_Music (gameplay), https://pixabay.com/music/main-title-epic-cinematic-journey-apex-308461/
- `victory-triumphant-main-good-b-music.mp3` — “Triumphant (Main)” by Good_B_Music (victory), https://pixabay.com/music/main-title-triumphant-main-348750/

The pages identify the tracks as free to use under the Pixabay Content License. All three pages also display “Content ID Registered”; retain the original MP3 files and a copy/screenshot of each license page with the project records.

The app player is wired to these local paths. Do not rename the files unless the paths in `index.html` are updated as well.
