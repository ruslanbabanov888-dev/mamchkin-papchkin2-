# Selected soundtrack assets

The original MP3 files are stored in this directory with their downloaded filenames:

- `nastelbom-cinematic-intro-485889.mp3` — “Cinematic” by NastelBom (menu), https://pixabay.com/music/ambient-cinematic-485889/
- `artur_aravidi_music-epic-cinematic-journey-apex-308461.mp3` — “Epic Cinematic Journey - APEX” by Artur_Aravidi_Music (gameplay), https://pixabay.com/music/main-title-epic-cinematic-journey-apex-308461/
- `good_b_music-triumphant-main-348750.mp3` — “Triumphant (Main)” by Good_B_Music (victory), https://pixabay.com/music/main-title-triumphant-main-348750/

The pages identify the tracks as free to use under the Pixabay Content License. All three pages also display “Content ID Registered”; retain the original MP3 files and a copy/screenshot of each license page with the project records.

The app player in `index.html` uses these exact local paths. Keep the filenames unchanged unless the player paths are updated too.
